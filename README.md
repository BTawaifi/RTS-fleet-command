# RTS Fleet Command 1.4.5

Single-player fleet command for FreeSpace Open, with optional direct ship control. Build fleets, defend command stations, and manage recovery or withdrawal as the battle escalates. Requires retail FreeSpace 2 assets; MediaVPs are optional.

- [Play and controls](core/README.md)

Runtime files live under `core/data`. Player packages exclude local pilots, settings, logs and caches. Original code, missions and table definitions use the [MIT license](LICENSE); third-party assets retain their owners' terms. See [asset credits and provenance](core/data/ASSET-CREDITS.txt), [FSPort credits](core/data/FSPORT-ASSET-CREDITS.txt) and [insignia credits](core/data/maps/README-insignias.txt). Redistribution terms for the Cairo/Arachnas assets and promotional artwork still need verification before publication.
